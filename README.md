# PL/SQL Database Assignment Scenarios

This repository contains PL/SQL solutions for database programming scenarios completed as part of academic coursework.

## Scenarios Included

### Scenario 1: Library Management System
- Book management
- Borrowing and returning books
- Due date handling
- Explicit cursors
- Exception handling

### Scenario 3: Student Hostel Room Allocation
- Room allocation management
- Student check-in and check-out
- Bed space tracking
- Explicit cursors
- Exception handling

### Scenario 4: Campus Clinic Medicine Dispensing
- Medicine stock management
- Dispensing medicines
- Reversing dispensing records
- Explicit cursors
- Exception handling

### Scenario 5: Engineering Workshop Tool Loans
- Tool loan management
- Tool returns
- Stock control
- Explicit cursors
- Exception handling

## Concepts Demonstrated

- Table Creation
- Primary and Foreign Keys
- SQL Queries
- Stored Procedures
- IF ELSIF ELSE Statements
- WHILE Loops
- FOR Loops
- Explicit Cursors
- Exception Handling
- Inventory and Resource Management
